# @anatolia-icons/svg

Türk kamu kurumları, üniversiteler, teknoloji ve ödeme markalarının SVGO ile optimize edilmiş saf SVG logoları.

Tam katalog ve katkı rehberi: [anatolia-icons](https://github.com/fikretsefa/anatolia-icons).

## Kurulum

```bash
pnpm add @anatolia-icons/svg
# veya
npm install @anatolia-icons/svg
```

## Kullanım

```ts
import edevletUrl from '@anatolia-icons/svg/kamu/edevlet.svg';
```

Kategori klasörleri:

| Yol | Açıklama |
| --- | --- |
| `@anatolia-icons/svg/kamu/*` | Kamu & devlet kurumları |
| `@anatolia-icons/svg/universite/*` | Devlet üniversiteleri |
| `@anatolia-icons/svg/teknoloji/*` | Teknoloji, savunma & açık kaynak |
| `@anatolia-icons/svg/finans/*` | Finans & ödeme standartları |
| `@anatolia-icons/svg/belediye/*` | Büyükşehir belediyeleri |
| `@anatolia-icons/svg/gokturk/*` | Göktürk alfabesi |
| `@anatolia-icons/svg/motif/*` | Anadolu kilim motifleri |

React bileşenleri için [`@anatolia-icons/react`](https://www.npmjs.com/package/@anatolia-icons/react) paketini kullanın.
